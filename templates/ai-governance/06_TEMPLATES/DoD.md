# Definition of Done

A work item is DONE only when ALL of these hold:

- [ ] Acceptance criteria met
- [ ] Code reviewed by someone (or a separate agent session) who didn't write it
- [ ] Automated tests added/updated and green
- [ ] Lint & format checks pass
- [ ] No new security warnings
- [ ] Docs updated (README/API) if behavior changed
- [ ] Deployed to staging and smoke-checked
- [ ] Board card closed with a link to the PR

"Done except…" is not done.
